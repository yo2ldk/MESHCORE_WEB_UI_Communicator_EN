🔑 PRIVATE CHANNEL
Enter AES-128 key in hex (32 characters = 16 bytes).
The key is sent directly to the radio via CMD_SET_CHANNEL.

📡 APRS-IS GATEWAY
Takes the GPS position of your local node (SELF_INFO / companion) and sends it periodically to APRS-IS as a regular tracker/iGate. Requires a licensed callsign and a valid APRS-IS passcode.
⚠ Connects via APRS-IS's WebSocket port (readwrite mode) — this is a real bidirectional link, so you get a login "verified/unverified" confirmation right here, unlike a fire-and-forget HTTP POST. Use a secure (wss) host such as ametx.com:8888, or srvr.aprs-is.net:8080 if your browser allows plain ws://.
