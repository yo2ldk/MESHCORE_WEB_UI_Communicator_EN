🔑 PRIVATE CHANNEL
Enter AES-128 key in hex (32 characters = 16 bytes).
The key is sent directly to the radio via CMD_SET_CHANNEL.

🌐 Scope (optional): a region name (e.g. ro-cs) that limits this channel's flood to repeaters configured for that same region — real network-level filtering via CMD_SET_FLOOD_SCOPE_KEY (companion firmware v12+ / v1.10+ region support required). Leave blank for classic flood (everywhere). You can also set this via the 🌐 button next to the channel selector — both are kept in sync.
🤖 BOT DIAGNOSTIC
The bot listens on the selected private channel.
Send test on that channel → you automatically receive RSSI, SNR, noise floor, hops, airtime, battery.
The key is unique and does not enter the public network.
